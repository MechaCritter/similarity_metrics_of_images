Dataset
=======

File: ``pyvisim/datasets/datasets.py``

The module bundles one dataset class,
:doc:`OxfordFlowerDataset <oxford_flower_dataset/oxford_flower_dataset>`, used
for the project's experiments and pretrained weights. It is a standard PyTorch
``Dataset``, so it works with ``DataLoader`` and the rest of the Torch
ecosystem.
